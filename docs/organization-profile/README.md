# BabyBloom

Helping young learners grow through interactive activities and personalized learning experiences.

BabyBloom is a graduation project exploring how Android learning activities, adaptive session planning, and parent-facing progress insights can work together.

## What we are building

- Interactive counting, matching, tracing, listening, speech, and story activities.
- Assessments and adaptive learning sessions.
- Child profiles and progress dashboards for parents.
- Educational insights informed by learning activity results.

## Built with

Kotlin · Jetpack Compose · Room · Hilt · CameraX · ML Kit · Gemini API

## Project status

We are preparing the project documentation and Android release. Setup instructions and release information will accompany the application repository as they become available.

## Our team

BabyBloom is a collaborative graduation project. This organization brings its code, documentation, and future releases together while preserving contributor attribution.
